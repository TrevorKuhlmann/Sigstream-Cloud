Developer API

Read your device telemetry via a REST endpoint or subscribe to live updates with Server-Sent Events (SSE). Authentication is per-device using your API key.

Authentication & Access

  • Send your API key in the header X-API-Key.
  • SSE in browsers: since EventSource can’t set headers, pass it as a query param: ?api_key=YOUR_KEY.
  • Bound device only: the key must be bound to a device. We’ll stream/query that device automatically.
  • Subscription required: the key’s owner must have a subscription in active or trialling status.
  • Security: keep your API key secret. Do not embed it in public pages or logs.

Read Historical Telemetry (REST)

Endpoint
GET /devapi/telemetry
Headers
X-API-Key: <YOUR_DEVICE_API_KEY>
Query params
  • since (optional): ISO8601 (e.g. 2025-08-30T06:30:19Z) or epoch seconds
  • until (optional): ISO8601 or epoch seconds
  • limit (optional): 1–1000 (default 100)

Example (curl):

KEY="YOUR_DEVICE_API_KEY"
SINCE="$(date -u -d '-1 hour' +%Y-%m-%dT%H:%M:%SZ)"
curl -s -H "X-API-Key: $KEY" \
  "https://sigstreamcloud.com/devapi/telemetry?limit=50&since=$SINCE"

Example (PowerShell):

$KEY   = "YOUR_DEVICE_API_KEY"
$SINCE = (Get-Date).ToUniversalTime().AddHours(-1).ToString("yyyy-MM-ddTHH:mm:ssZ")
curl.exe -s -H "X-API-Key: $KEY" `
  "https://sigstreamcloud.com/devapi/telemetry?limit=50&since=$SINCE"

Response shape:

[
  {
    "id": 12345,
    "device_id": "MACHINE-ABC",
    "label": "Line 3 Sensor",
    "data": "{\"temp\": 24.8, \"rpm\": 1500}",
    "timestamp": 1735581402,
    "ts_iso": "2025-08-30T07:56:42Z"
  }
]

Live Stream (SSE)

Endpoint
GET /devapi/stream
Auth
  • curl / tools: header X-API-Key
  • Browser EventSource: query param ?api_key=YOUR_KEY

Example (curl):

KEY="YOUR_DEVICE_API_KEY"
curl -N -H "X-API-Key: $KEY" https://sigstreamcloud.com/devapi/stream

Browser example:

<script>
const es = new EventSource("/devapi/stream?api_key=YOUR_DEVICE_API_KEY");

// live telemetry
es.addEventListener("telemetry", (e) => {
  const row = JSON.parse(e.data);
  console.log("telemetry", row);
});

// heartbeats
es.addEventListener("heartbeat", (e) => {
  const hb = JSON.parse(e.data);
  console.log("heartbeat", hb);
});

es.onerror = (e) => console.warn("SSE error:", e);
</script>

Events you will see:

event: telemetry
data: {"device_id":"MACHINE-ABC","label":"Line 3 Sensor","data":"{\"rpm\":1510}","timestamp":1735581402,"ts_iso":"2025-08-30T07:56:42Z"}

event: heartbeat
data: {"device_id":"MACHINE-ABC","status":"online","timestamp":1735581402,"ts_iso":"2025-08-30T07:56:42Z"}

Status Codes

  • 401 Missing API key
  • 403 Invalid/revoked API key
  • 403 API key is not bound to a device
  • 403 Subscription inactive (requires active or trialling)
  • 200 Success
