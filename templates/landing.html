How it works

1) Create an API key

Per-device keys keep data clean and tenant-safe.

2) Install the Windows agent

Reads telemetry from a COM port (e.g., COM3), buffers offline, and forwards securely.

3) View or build

Frequently asked

Does it work without internet?

Yes. The Windows agent buffers locally and forwards when connectivity returns.

How do I stream live data?

Use our SSE endpoint with EventSource, or just open the built-in dashboard.

What about Linux/macOS?

Windows agent is available today. Linux/macOS agents are on the roadmap.

How are devices secured?

Each device gets its own API key, tenant-mapped, with server-side validation.
