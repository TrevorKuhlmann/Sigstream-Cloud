Verify your download

We publish a SHA-256 so you can confirm the installer hasn’t been tampered with.

PowerShell

Get-FileHash .\SigStreamAgent-Setup.exe -Algorithm SHA256

Compare the result to the SHA-256 shown above.

Command Prompt

certutil -hashfile SigStreamAgent-Setup.exe SHA256

Heads-up: no code-signing certificate yet

We’re awaiting our DigiCert code-signing certificate. Until then, Windows SmartScreen may warn that the app is from an unknown publisher. You can proceed safely by verifying the SHA-256 above, then follow these steps:

  1. Double-click the installer. If you see “Windows protected your PC”, click More info.
  2. Confirm the app name is SigStreamAgent-Setup.exe and publisher shows Unknown.
  3. Click Run anyway.
  4. If Windows blocks the file after download, right-click → Properties → tick Unblock → OK, then run again.

Download tips

  • Edge “Unconfirmed … .crdownload”: this appears while the download is still in progress or flagged. Open Edge’s Downloads panel and choose Keep → Keep anyway. It will rename to the final .exe once complete.
  • For the smoothest experience use the **Download** button above (Chrome or Edge both work). If a browser still saves with a generic name, right-click the link → Save link as… and ensure the filename ends with SigStreamAgent-Setup.exe.
